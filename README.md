## 📋 COMMANDS

```
/customsword <type>  - Get a custom sword
/swordstats          - View your sword's stats (hold it)
/swordhelp           - Show this help menu
```

### Available Sword Types:
- **Original**: `inferno`, `frostbite`, `thunder`, `shadow`, `celestial`
- **Legendary**: `void_ripper`, `chrono_blade`, `gravity_well`, `soul_reaver`, `necro_scythe`, `prisma_edge`, `phoenix_wing`, `quantum_blade`, `echo_sword`, `entropy_saber`

---

## 🎮 HOW TO PLAY

1. **Get a sword**: `/customsword quantum_blade`
2. **Check stats**: `/swordstats` (while holding sword)
3. **Attack**: Left-click for normal damage + bonus
4. **Use ability**: Right-click to activate special ability
   - ⏱ 10-second cooldown between abilities
   - Range varies: 10-20 blocks depending on sword

## 📦 INSTALLATION

1. Clone or download this repository
2. Run `mvn clean package`
3. Copy the JAR file from `target/` to your server's `plugins/` folder
4. Restart the server
5. Use `/customsword` to get started!

---

## 🔧 REQUIREMENTS
