## 📋 COMMANDS

```
/customsword <type>           - Get a custom sword
/swordstats                   - View your sword's stats
/swordhelp                    - Show abilities guide

/swordskin <skin_name>        - Apply a static skin
/skinslist                    - View all 45 static skins

/animatedskin <animation>     - Apply an animated skin
/animatedskinlist             - View all 30 animated skins
/animatedskin stop            - Stop animation

/soundeffect <effect_name>    - Apply a sound effect (NEW!)
/soundeffectlist              - View all 30 sound effects (NEW!)
/soundeffect stop             - Stop sound effect
```

## 🎮 HOW TO PLAY - ULTIMATE CUSTOMIZATION

### Step 1: Get a Sword
```

```

```

```

### Step 3: Add Animation (Optional)
```

```

### Step 4: Add Sound Effect (Optional)
```
/soundeffectlist
/soundeffect quantum_portal
```

### Combat
- **Left-click**: Normal attack with damage bonus
- **Right-click**: LEGENDARY ABILITY (10s cooldown)

## 🔊 SOUND EFFECT FEATURES

### How They Work
- **Continuous Playback**: Sounds play repeatedly while holding the sword
- **Smart Timing**: Different speeds for different effects (8-25 ticks)
- **Spatial Audio**: Sounds play for nearby players too!
- **Full Minecraft Sounds**: Uses vanilla Minecraft sound events
- **Auto-stops**: Stops when you drop the sword or switch items
- **Combines with Everything**: Use static skin + animation + sound for maximum immersion!

### Sound Types & Speeds
- **FASTEST (8-9 ticks)**: Chrono Ticking, Prisma Chaos - rapid-fire effects
- **FAST (11-13 ticks)**: Quantum Portal, Thunder Zapping
- **MEDIUM (14-17 ticks)**: Most effects - balanced and smooth
- **SLOW (18-25 ticks)**: Void Rumble, Entropy Decay - deep and dramatic

### Vanilla Minecraft Sound Events Used
- Lightning strikes & thunder ⚡
- Portal ambient & travel sounds 🌀
- Warden audio & sonic booms 👹
- Note block music & chimes 🎵
- Fire, ice, and particle effects
- 50+ more vanilla sounds!

## 📦 INSTALLATION

1. Clone or download this repository
2. Run `mvn clean package`
3. Copy the JAR file from `target/` to your server's `plugins/` folder
4. Restart the server
5. Use `/swordhelp` to get started!
